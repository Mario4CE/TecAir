## 🔄 FLUJO DE SINCRONIZACIÓN

1. API devuelve vuelos con estructura:
   {
	 "id_vuelo": 1,
	 "origen": "SJO - Juan Santamaría",
	 "destino": "LIR - Guanacaste",
	 "precio": 105.00,
	 "fecha_salida": "2026-06-01",
	 "hora_salida": "08:00:00",
	 "asientos_disponibles": 116
   }

2. SyncService.DescargarVuelosAsync() deserializa en VueloApiDto

3. Mapea a modelo Flight de SQLite:
   - Origin ← Origen (del API)
   - Destination ← Destino (del API)
   - Price ← Precio (del API)

4. Guarda/Actualiza en SQLite local


## 🗄️ ESQUEMA SQLite

Tabla: Flights
Nuevas columnas:
- Origin TEXT DEFAULT ''
- Destination TEXT DEFAULT ''
- Price DECIMAL DEFAULT 0

Nota: SQLite-net crea/altera automáticamente al llamar CreateTableAsync<Flight>()

## 🐛 TROUBLESHOOTING

Si SQLite no muestra las nuevas columnas:
1. Limpiar la app data (reinstalar)
2. Verificar que DatabaseService llama CreateTableAsync<Flight>()
3. Revisar logs en Output Window

Si no se sincronizan los vuelos:
1. Verificar conectividad de red
2. Revisar que el endpoint /api/vuelos devuelve origen, destino, precio
3. Revisar logs de SyncService en Output Window
